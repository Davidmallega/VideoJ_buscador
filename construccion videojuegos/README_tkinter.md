# Aplicación CRUD de Videojuegos (Tkinter)

Esta aplicación de escritorio permite gestionar una base de datos de videojuegos, utilizando una interfaz gráfica desarrollada en Tkinter. Soporta operaciones de creación, lectura, actualización y eliminación (CRUD) sobre una base de datos MySQL.

## Archivos principales
- `interfaz.py`: interfaz gráfica.
- `modelo.py`: operaciones sobre la base de datos.
- `conexion.py`: conexión a MySQL.
