# Prueba de Integración: Envío de Archivos Multimedia

Aplicación mínima en Flask para simular el envío de archivos y registrar su recepción en una base de datos. Sirve como base para pruebas de integración y uso de herramientas como Selenium y JMeter.

## Archivos principales
- `app.py`: lógica de carga y guardado.
- `formulario.html`: interfaz para subir archivos.
- `conexion.py`: conexión a base de datos MySQL.
