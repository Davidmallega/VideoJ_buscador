# Aplicación Web Flask: Buscador de Videojuegos

Versión web de la aplicación de videojuegos con Flask. Permite realizar búsquedas en una tabla cargada desde MySQL y mostrar los resultados en una interfaz HTML.

## Archivos principales
- `app.py`: servidor Flask.
- `modelo.py`, `conexion.py`: lógica de negocio y conexión.
- `index.html`: interfaz web.
